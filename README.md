Amazon Sales Analysis

Project Overview

This project analyzes Amazon sales data using Microsoft Excel to understand sales performance and product profitability.

Tools Used

- Microsoft Excel
- Data Analysis
- Data Visualization
- Charts and Dashboard

Key Business Insights

- City with Maximum Sales
- State with Maximum Sales
- Most Profitable Product
- Least Profitable Product

Project Objective

To analyze sales data, identify business trends, and present useful insights through an Excel dashboard.
