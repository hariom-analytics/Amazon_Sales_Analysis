Amazon Sales Analysis

Project Overview

This project analyzes sales data using Microsoft Excel and presents the results through interactive dashboards.

Work Completed

- Data cleaning and preparation
- Pivot Table analysis
- Distribution Dashboard
- Sales Dashboard
- Salesperson KPI Dashboard
- Interactive year filters

Tools Used

- Microsoft Excel
- Pivot Tables
- Excel formulas
- Charts and slicers

Project Objective

To organize sales data, analyze business performance, and present useful information through clear and interactive visual reports.

Deliverables

- Excel workbook
- Three dashboard screenshots
- Sales analysis and KPI reporting
